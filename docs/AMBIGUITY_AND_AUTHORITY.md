# Ambiguity and authority

The deterministic engine is authoritative only for encoded, documented rules. A confidence number never upgrades an unresolved token to a resolved one. A lexical reading is marked `LEXICON_RESOLVED`; an unresolved token can show a consonantal scaffold but carries zero confidence and an explicit warning that no short vowels were fabricated.

Future assisted resolution must follow: proposal → evidence/confidence → deterministic IJMES validation → accepted candidate or review required. An LLM may not decide mappings, Unicode normalization, title formatting, or final output. User corrections can later become persisted lexicon entries with their own `USER_OVERRIDE` status and provenance.
