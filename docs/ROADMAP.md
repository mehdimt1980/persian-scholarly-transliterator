# Roadmap

1. **Phase 2A:** source-aware vowel evidence, vocalized lookup, ZWNJ structure, confirmed izāfat, and conservative relation candidates.
2. **Recommended Phase 2B:** add cited, reviewed semantics for a deliberately small set of productive suffixes and ZWNJ constructions, with morpheme-level tests and no general parser.
3. Build a reviewed lexicon with alternate readings and place/person-name metadata.
4. Add user overrides and a relation-review queue.
5. Add an assisted resolver behind the deterministic validator.
6. Add batch bibliography, CSV, Zotero, and EndNote-safe exports.

Phase 2A deliberately stops before productive suffix classification or compound analysis.
