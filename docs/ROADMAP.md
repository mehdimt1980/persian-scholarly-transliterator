# Roadmap

1. Expand source-grounded rule coverage and cite/record any chart-versus-current-guide differences.
2. Add a morphology/context layer for productive izāfat, suffixes, compounds, and explicit vowel marks.
3. Build a reviewed lexicon with alternate readings and place/person-name metadata.
4. Add user overrides and a review queue for unresolved tokens.
5. Add an assisted resolver behind the deterministic validator.
6. Add batch bibliography, CSV, Zotero, and EndNote-safe exports.

This phase deliberately stops after the first vertical slice.
