# Engine-Blindness Declaration

Phase 4.6B scholarly adjudication was performed before any benchmark evaluation of the current engine.

The following were not used to choose gold truth:

- current transliteration output;
- current lexicon coverage;
- current unresolved/ambiguous status;
- assisted resolver suggestions;
- benchmark pass/fail metrics;
- release-gate outcomes.

Gold decisions were based on current IJMES rendering policy plus the frozen external evidence from Phase 4.6A.

Any later mismatch between engine output and this adjudication is an engine/runtime finding, not permission to rewrite the expected output.
