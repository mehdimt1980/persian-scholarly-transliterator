# No Engine Evaluation Declaration

Phase 4.6B sets scholarly truth before measuring the current implementation.

During this phase:

- the frozen external benchmark is not run through the transliteration engine to choose expected outputs;
- engine output is not used to revise adjudication decisions;
- current lexicon coverage is not used as reading authority;
- runtime limitations are documented as limitations rather than repaired by changing gold truth.

The first benchmark-vs-engine comparison belongs to Phase 4.6C after sign-off and gold promotion.
